# v3.3.65 同期時のプレー情報保護・表示修正

## 適用順序
1. 本番DBのバックアップ状況を確認し、Supabase SQL Editorで `supabase/v3.3.65_preserve_clear_only_sync.sql` を実行する。既存データ削除はしない。
2. SQL成功後、同梱の変更ファイルをGitHubに反映する。
3. 少数曲の公式同期でクリア、FAILED（スコア0含む）、今作だけの記録を確認する。

## 修正点
- 詳細ページから対象譜面のプレー回数・スコアが取得できないときは同期全体を中止。FAILEDへ置き換えない。
- スコア0でもプレー済み（FAILED、CLEAR、FULL COMBO、PERFECT）の記録を中継・RPCに渡す。
- SQL関数の条件を修正。これまでのv3.3.65候補で誤って除外されていたスコア0のCLEAR系レコードも保存する。完全な未プレー・スコア0・メダルなしのみ除外する。
- スコア0でFAILEDメダルがある曲を表示対象に含め、キャッシュを更新する。
- PSR計算式・手動メダル・曲マスター照合ルールは変更しない。

## 未検証
公式サイトとSupabase本番環境を利用した結合試験、および端末別（PC、iPhone Safari、Android Chrome）の実機試験は未実施。ユーザー申告の曲名・譜面も未確定のため、報告された全症状の解決は保証できない。
